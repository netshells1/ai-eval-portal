# 人工智能项目评估平台

面向区级 AI 项目立项评审的交互式演示平台。评审人员可以从一个申报项目出发，查看建设必要性与预算依据，比较候选企业的交付能力，并追溯可复用的技术底座、同类案例和设备报价。

## 快速开始

在仓库页面选择 **Code → Download ZIP**，解压整个目录，双击 `index.html` 即可浏览。项目使用原生 HTML、CSS 和 JavaScript，直接从本地文件运行，支持离线演示。请把八个 HTML 文件和 `assets/` 保持在同一目录。

| 演示环境 | 启动 | 结束 |
| --- | --- | --- |
| Windows | 双击 `启动项目.bat` | 双击 `关闭项目.bat` |
| macOS | 双击 `启动项目.command` | 双击 `关闭项目.command` |

演示时按数字键 `1` 至 `8` 切换栏目，按 `?` 查看快捷键。

## 评审工作流

| 栏目 | 可以查看什么 |
| --- | --- |
| 项目评估 | 从需求必要性、技术适配、造价合理性、企业履约能力、园区产业适配和安全合规六个维度审视项目，查看各维度权重与评价指标。 |
| 造价核定 | 通过瀑布图查看示例项目从申报金额到核定区间的变化，逐项检查工程量、市场单价与复用抵扣。 |
| 场景匹配 | 选择申报项目，对照其需求、可复用组件和候选企业，查看匹配理由与待核验事项。 |
| 资源库与典型案例 | 在企业库、技术与底座库、项目与场景库、软硬件价格库之间追踪关联记录，按设备或型号打开报价凭证。 |
| 询价标准 | 按地区、层级、文件名称或文号检索 33 条地区记录，查阅文字摘录、表格和参考图。 |

## 资源库的数据口径

资源库采用《区级AI项目评估系统-数据.xlsx》的离线快照。企业库列出 20 家企业，项目与场景库列出 20 个需求场景。技术与底座库按来源索引 20 条企业能力、11 组案例复用要素和 2 项可共享设备。表内的模拟关联、推演信息和待核事项随记录展示。

软硬件价格库分别收录 15 项设备价格基准和 30 条视频会议询价凭证。设备详情保留原始计量单位，并列出工作表中 2027 年估算的 P25、P50、P75。整包报价按批展示。

## 用一个案例走通询价

打开 **典型案例 → 视频会议系统**。同型号的现代中庆 M2600 导播服务器有两份报价，分别为 **12,000 元/台**和 **15,500 元/台**。点开任一报价，即可核对该份凭证的 24 条参数对照。进入完整档案后，还可切换到软件客户端、话筒等其他询价项。

案例数据来自询价导出记录，共 10 个询价项、30 条凭证和 459 条参数对照。28 条凭证记录了单价，其余两条标为“未提供”。这些价格用于比对样本。企业画像、项目评分、推荐排序和核定金额采用演示数据。地区标准收录的是整理时的摘录，具体适用范围以发布机构文件原文为准。

## 演示素材与播放

14 张栏目及场景配图放在 `assets/`，6 段静音视频放在 `assets/motion/`。首页、平台介绍、资源库和询价标准各有一段背景视频。全屏目录的首页预览使用薄雾城市画面，资源库预览使用第二段机房画面。场景匹配页使用城市路口照片。

从任一页面首次进入时，开场进度按素材实际就绪数量更新，同时最多准备两个文件。同一标签页切换栏目时直接显示新页，横幅视频就绪后淡入。后台标签、滚出视口的横幅会暂停，系统开启“减少动态效果”时使用静态图。点击开场画面可跳过等待，视频读取或播放失败时保留配图。每个视频的静态封面、栏目字段和预加载逻辑分别在 [图片与栏目配置](./assets/portal-data.js) 和 [媒体脚本](./assets/portal-media.js) 中维护。
